# Qualixar Homebrew tap

```sh
brew install qualixar/tap/touchless-mac
```

| Formula | What it is |
|---|---|
| [touchless-mac](https://github.com/qualixar/touchless-mac) | Control your Mac with your hand through the built-in camera: point, pinch to click, thumb + ring finger to scroll, wave to switch apps. Fully local, written in Rust. Apple Silicon. |

After installing, run `touchless-mac doctor` to check the camera and Accessibility permissions.
